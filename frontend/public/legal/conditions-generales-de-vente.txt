ARTICLE 2 – FORMATION DU CONTRAT

Le contrat est réputé formé dès :

• signature d’un devis ;
• accord écrit par email ;
• validation écrite par message ;
• bon pour accord ;
• paiement d’un acompte ;
• commencement d’exécution ;
• validation d’un brief ;
• lancement opérationnel demandé par le client.

Les échanges électroniques, confirmations écrites, validations, comptes-rendus, correspondances professionnelles et paiements ont valeur probatoire dans la relation contractuelle.

100% payable d’avance

---

3.3 – Coaching / Accompagnement

100% payable d’avance

Toute séance réservée est due.

---

3.4 – Formation

100% payable avant démarrage

La réservation devient ferme après règlement.

---

3.5 – Supports commerciaux / Catalogues / Branding / Création visuelle

100% payable d’avance

Le client règle distinctement :

Le budget publicitaire reste la propriété exclusive du client.

MCE ne finance aucune campagne pour le compte du client.

ARTICLE 4 – DÉLAIS D’EXÉCUTION

Les délais communiqués constituent des estimations.

Ils commencent uniquement après réunion cumulative des conditions suivantes :

• validation écrite ;
• paiement requis ;
• réception complète des éléments ;
• brief validé ;
• accès techniques transmis ;
• arbitrages fonctionnels arrêtés.

Les délais sont automatiquement suspendus en cas de :

• retard client ;
• absence de validation ;
• brief incomplet ;
• modification de stratégie ;
• changements successifs ;
• demandes complémentaires ;
• indisponibilité du client ;
• blocage tiers (hébergeur, API, store, paiement, etc.) ;
• cas de force majeure.

Aucune pénalité ne peut être imputée à MCE dans ces cas.

Pour les projets complexes (applications, logiciels, plateformes, SaaS, marketplace), aucun délai ferme ne peut être contractuellement garanti, sauf engagement écrit exprès sur un jalon précis.

Les roadmaps communiquées constituent des estimations évolutives.
